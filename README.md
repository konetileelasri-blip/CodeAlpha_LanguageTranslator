# 🌐 AI Language Translator

An interactive AI-powered Language Translation Tool developed as part of the CodeAlpha Internship Task.

This web application allows users to enter text, select source and target languages, and translate the text using a translation API.

## ✨ Features

- 🌍 Translate text between multiple languages
- 🔄 Swap source and target languages
- 📋 Copy translated text
- 🔊 Listen to translated text using text-to-speech
- ⚡ Fast and simple user interface
- 📱 Responsive design for different screen sizes
- ❌ Input validation for empty text

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Translation API
- Web Speech API

## 🌎 Supported Languages

The application currently supports:

- English
- Telugu
- Hindi
- French
- Spanish
- German

## ⚙️ How It Works

1. Enter the text you want to translate.
2. Select the source language.
3. Select the target language.
4. Click the *Translate* button.
5. The translated text will appear in the output section.
6. Use *Copy* to copy the translation.
7. Use *Speak* to hear the translated text.
8. Use the *Swap* button to switch the languages.

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html using Live Server.
4. Enter text and select the required languages.
5. Click *Translate*.
